# Master Execution Plan — The Blue Ants Luxury Overhaul

## Overview
Transform The Blue Ants corporate gifting web application into a psychological, high-end editorial luxury gifting platform (Tier 1 standards: Net-a-Porter, Tiffany & Co., Aesop aesthetic) with 60FPS unboxing canvas, frictionless B2B conversion flows, mobile bottom sheets, and static Vercel deployment reliability.

## Phases & Strategy (Project Pattern - Dual Track)

### Phase 0: Survey & Scope Specification
- Survey 1 (Spec Miner): Comprehensive audit of current UI/UX, styles, Tailwind/CSS config, assets, typography, and AI-cliché elements.
- Survey 2 (Explorer): Comprehensive codebase architecture mapping (components, state management, drawers/modals, Canvas unboxing engine, dependencies, build setup).
- Survey 3 (Explorer): B2B conversion flows, catalog data structure, inquiry formatting, WhatsApp concierge integration, and mobile responsiveness.
- Output: Synthesize into root `PROJECT.md` with Feature Inventory, Architecture, Interface Contracts, and Milestones.

### Track A: Implementation Track (Milestones)
- **Milestone 1**: Bespoke Editorial Luxury Visual Identity & Anti-AI Polish
  - Color palette (Obsidian Noir `#07090e`, Warm Charcoal `#10141d`, Champagne Gold `#d4af37`/`#e6ca65`).
  - Classical luxury typography (Cinzel / Cormorant Garamond headings + Inter / Plus Jakarta Sans body, modular scale, 65-75ch limit).
  - Artisanal whitespace, hairline borders `rgba(255, 255, 255, 0.06)`, subtle soft shadows.
  - Elimination of AI glows, harsh neon, dashed borders, generic badges.
- **Milestone 2**: Cognitive Psychology & B2B Conversion Architecture
  - Tiered catalog groupings (Executive VIP, Welcome Kits, Sustainable Eco-Luxe, Gourmet Connoisseur).
  - F/Z-pattern visual hierarchy, value proposition anchors (Bespoke Branding, Tiered Savings, WhatsApp Concierge `+91 9916418879`).
  - Frictionless B2B Quote Drawer with instant WhatsApp pre-formatted dispatch.
- **Milestone 3**: Tactile 60FPS Unboxing Canvas Experience
  - Hero canvas with smooth frame scrubbing, adaptive lerp inertia, async image pre-decoding, zero frame drops.
  - Floating Unboxing Progress Pill with live percentage & "Skip to Catalog" jump.
- **Milestone 4**: Responsive Mobile & Touch Perfection
  - Mobile bottom sheets for Quick View & Faceted Filters.
  - Bottom thumb navigation dock with live quote badge count.
  - Touch targets >=48dp, CLS: 0, PWA manifest support.
- **Final Milestone**: 100% E2E Verification & Adversarial Coverage Hardening (Tiers 1-5).

### Track B: E2E Testing Track (Requirement-Driven)
- E2E Test Suite Orchestration (Tiers 1-4: Feature Coverage, Boundaries/Corners, Cross-Feature Combinations, Real-World B2B Application Scenarios).
- Publish `TEST_READY.md`.

## Verification & Integrity Policy
- Strict Explorer -> Worker -> Reviewer -> Challenger -> Auditor verification loop on all milestones.
- Binary veto on any Forensic Auditor integrity violation.
